# Propuestas de UI (maquetas)

Tres direcciones para la UI del juego (manual, ranking, tarjeta de victoria, HUD), no para la escena.
Solo maquetas: nada de esto se carga en el juego.

- **A · Cuaderno de campo**: papel cuadriculado, tinta sepia, IM Fell English, marca a mano en tu fila.
- **B · Grimorio rubricado**: impresión a dos tintas (negro + rojo), EB Garamond / Cormorant SC, doble filete, numerales romanos.
- **C · Lámina nocturna**: lámina oscura con filetes finos, Cormorant Garamond, símbolos sobre círculo guía, acento latón.

Ver con `npm run dev` en `/estilos/ui/?p=a|b|c&s=hud|manual|ranking|victoria`.
Capturas comparativas: `estilos/capturas/ui-propuestas-*.png`.
